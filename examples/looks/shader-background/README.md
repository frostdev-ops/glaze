# Soft Rings

Open Glaze's **Look → Background**, choose **Custom shader**, and paste [shader.glsl](shader.glsl) into the shader box.
The background uses your Look's first two colours and becomes part of the Look you wear.
Use **Copy theme code** to share it. To keep a saved copy, paste that code into **Theme code**, press **Preview**,
then **Save to favorites**. It needs no mod installation or permissions.

# 3.0.1: shared surfaces and animated local pets

Base: clean rewritten `origin/main` at `c30814e3c7bc694c5b241c5b8cd7d9bba48028b3`. No old-history commits are merged or pushed. This branch prepares features for 3.0.1; it does not publish a release.

## Surfaces

`lib/surfaces.js` owns the surface schema, boundary sanitizer and pure variable painter. `defaults.js` includes the schema; `content.js`, editor pages/previews and document tools use its painter. `features/surfaces.css` derives opaque/tinted fills, role-specific alpha and borders. Existing styles consume them; the editor stays lazy.

Catalogue: Ultra cards, module rows, right-column blocks, MUI papers/drawers, page/course headers, menus and dialogs; Canvas cards, module/content panels, headers/menus; Moodle/Boost cards, content rows, drawers, menus and dialogs; Glaze widgets, To Do, hub, toolbar, notes, course menu, tooltips, popup/editor sections, standalone Share Sessions, and isolated viewer/Gradescope toolbars. Embedded dialog and shadow-root styles are part of the same audit. Native document pixels and annotation layers retain their document meaning.

Automatic opacity leaves each role’s original fill/alpha unchanged. With explicit opacity, solid backgrounds and zero blur remain opaque. Small rows never gain backdrop blur. Frost is a static local image in the element’s own background, clipped by its radius. Shadows retain their existing geometry while strength/color are adjustable. Corners that used fixed lengths now scale from the Look radius; circular icons and functional pill shapes stay circular/pill shaped.

The final default comparison captured 120 static cases: ten Looks × three LMS previews × light/dark palettes × outline/dashboard, using the real unpacked extension. 118 images were byte/pixel identical; two Terminal outline cases differed by ten pixels each in previously fixed corners. This is a real geometry correction, not a claim of zero differences. Remote fonts and WebGL were blocked in this deterministic check; animated-scene pixels and live authenticated LMS coverage are not established by it. The same pixel result held after the independent review fixes.

## Animation/import

`lib/petsprites.js` addresses both ChatGPT layouts: v1 1536×1872 and v2 1536×2288, 192×208 cells, eight columns. Nine states use minimum frame counts 6/8/8/4/5/8/6/6/6; contiguous legacy runs may use up to eight frames per state. Counts come from decoded alpha, not metadata. v2 adds two rows of eight gaze cells clockwise from up. Rime’s existing seven-frame idle run is retained. Unknown versions or dimensions are refused before image decode. Both `name` and `displayName` metadata conventions are accepted; metadata URLs, paths, claimed frame counts and scripts are ignored. PNG/WebP bytes are decoded, validated and re-encoded; ZIP parsing reuses bounded `GZ_DOCTEXT.unzip`. Files never leave the device.

Only the extension editor can import/delete. An eligible LMS page with Pet habitat on can read the library and selected picture; it cannot write picture bytes. The local library is bounded and failed reads/writes preserve its prior state. Existing XP, provider timestamps, streak days, looks and decoration positions are retained separately from sprite selection. Outfits apply to the Classic buddy; their saved choice is kept while an animated character is selected.

`lib/petplayer.js` draws one frame at 8fps on a bounded canvas, pauses when hidden/offscreen, uses a resting still under reduced motion or Glaze Motion off, and tears down listeners/timers/pictures on removal, pagehide or extension invalidation. Click waves; Enter/Space jumps; v2 gaze follows the pointer within the pet.

Five dedicated art agents produced Ember (fox), Luna (owl), Mochi (cat), Sprout (dragon), and Pebble (capybara). Each final asset must pass exact-byte structural and motion/registration gates, with source-grounded generation and separate state/gaze reviews. Source strips and QA previews remain outside the package. The owner also requested their existing Rime arctic fox and an original animated Glaze droplet. The final Glaze atlas is 1,783,056 bytes and passed structural/motion checks plus three blind axis reviews; its flexible-body turns have the documented 5-pixel gaze drift and 1.307 width ratio. Rime’s original metadata and WebP are copied byte for byte; the importer was tested against that real package. The editor defers atlas reads until the pet-library section becomes visible. ChatGPT compatibility does not install anything in ChatGPT or connect an OpenAI account.

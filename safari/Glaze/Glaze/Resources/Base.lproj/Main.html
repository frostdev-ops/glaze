Glaze for Safari

Your colors on Blackboard Ultra, Canvas and Moodle.

Copies Glaze into Applications, then shows you how to turn it on in Safari.

Turn on Glaze in Safari

Glaze is installed. Two steps in Safari and you’re done.

  1. 1Turn on Glaze in Settings

    In Safari’s Settings → Extensions, select the checkbox beside Glaze.

    Checking Safari…

    Extensions
    Glaze

  2. 2Allow it on your school’s website

    Open Blackboard Ultra, Canvas or Moodle in Safari, click the Glaze button in the toolbar and choose Always Allow on This Website. Then reload the page.

    school.edu/ultra/courses
    Allow for One Day Always Allow on This Website

Glaze is enabled. Website access is managed separately in Safari, for each profile you use.

Next steps and permissions

From Glaze’s Safari button, choose Open the editor to try Looks and settings with the built-in sample page.

Enable Glaze in each Safari profile where you use your school’s site. Private browsing has a separate switch in Safari’s extension settings.

You can close this app. Safari runs the extension when needed; no login item or always-running setup app is required.

Updates

The App Store updates Glaze and its Safari extension. Manage automatic app updates in the App Store’s settings.

Checks can run quietly while you use Glaze in Safari. macOS may ask for approval if installing an update needs it.
